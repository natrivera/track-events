# Track Events

One place to track upcoming HPDE / track-day events at the Southern California tracks I run, instead of checking MotorsportReg plus every organizer's calendar separately.

**Data:** `events.json` — one entry per event: date, track, organizer, price, run group, my status (registered / chosen / option), deadlines, and the date each entry was last verified.

**Tracks covered:** Streets of Willow, Big Willow, Buttonwillow (13CW + The Circuit), Adams Motorsports Park, Chuckwalla, Auto Club Speedway (Fontana), Laguna Seca. Autocross venues: Storm Stadium (Lake Elsinore), Angel Stadium (Anaheim).

**Organizers watched:** SoCal Drivers Club, Speed Ventures, OnGrid, Lotus Club, Adams Time Attack, Topak Racing Events, Canyon Run Sundays, Extreme Speed Track Events, Tamale Track Days, Speed District, Cal Club Autocross (SCCA), Corner Exit, NASA SoCal, plus MotorsportReg listings for the tracks above.

Refreshed weekly. Prices and availability are only as current as each entry's `verified` date — confirm on the organizer's site before registering.
